UpdateAPP

Ứng dụng quản lý và cập nhật phần mềm tối ưu dành riêng cho thiết bị Android TV / TV Box.

## Tính năng chính
- Giao diện Dark Mode tối ưu điều khiển từ xa (D-pad).
- Kiểm tra phiên bản và cập nhật ứng dụng từ máy chủ JSON.
- Quản lý danh sách ứng dụng đã cài đặt trên thiết bị.
- Hỗ trợ cài đặt tuần tự và tự động dọn dẹp bộ nhớ đệm sau khi cài.

## Môi trường phát triển
- Ngôn ngữ: Kotlin
- Nền tảng: Android TV (API 21+)
